## The Constitution

1. **Version is Law**: Do not "patch" architecture documents; only "evolve". Changes must create a new version.
2. **Explicit Context**: Write decisions into ADRs; do not leave them in "chat memory".
3. **Cross-Validation**: Check against `05A_TASKS.md` and `05B_VERIFICATION_PLAN.md` before coding. Am I doing what was planned?
4. **Aesthetics**: Documentation should be beautiful. Make good use of Markdown and clear hierarchical structure.

---

## 5. Workspace Rules for AI & Subagents

> [!IMPORTANT]
> **Mandatory Rules for All AI Sessions & Subagents**:
> 1. **Pipeline Compliance**: All development and task execution must strictly follow `.anws/v1/05A_TASKS.md` and `05B_VERIFICATION_PLAN.md`. Read the task checklist before writing any code.
> 2. **Quality Gate Enforcement**: Any code changes must be executed in the virtual environment and pass 100% of formatting and unit tests before committing or presenting work to the user:
>    - `.\.venv\Scripts\black.exe --check .` (or `black .`)
>    - `.\.venv\Scripts\python.exe -m pytest tests/ -v`
> 3. **v1.1 Feature Tracking**: All new features, extended capabilities, and out-of-scope requests (e.g., feedback synchronization, interactive review, etc.) **must** be logged and tracked in the `v1.1 Post-v1 Pipeline Extensions` task block of `.anws/v1/05A_TASKS.md`. Uncontrolled feature sprawl is prohibited.
